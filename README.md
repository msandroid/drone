# MORI AIR Concept Store

A responsive Japanese storefront concept for a white and forest-green iPhone-docking drone with three protected ducted fans.

## Preview

This is a static HTML, CSS, and JavaScript site. Open `index.html` in a browser or serve this directory with any static file server. It has no build step or runtime dependencies.

## Current scope

- Product concept, design story, views, and proposed specifications
- Foldable three-duct layout that targets an iPhone Pro Max-sized footprint when stored
- Responsive navigation and a browser-local shortlist
- Vercel static output configuration and security headers

The aircraft is a design concept. The listed price is a reference only; sales, reservations, payments, customer data collection, and order storage are not available.

The folding dimensions and hinge concept are visual targets only and have not been validated with a physical prototype.

## Deployment

The project is configured for Vercel with the repository root as its output directory. No environment variables are required. Excluded local work files are listed in `.vercelignore`.
